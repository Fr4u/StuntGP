The game

The original game. A new, native engine.

Stunt GP is a radio-controlled car racer on tracks full of ramps, jumps and steeply banked corners. StuntGP NEW rebuilds the whole path through the game: language selection, title screen, menus, name entry, choice of mode, vehicle and track, the race, the results and the return to the menu — all in one consistent game world.

It is neither an emulator nor a wrapper around the old EXE file. Driving mechanics, track contact, rival AI and the camera are new native code rebuilt from the instructions of the original program. The game uses the original data: models, textures, fonts, music and effects.

Where the original behaviour has not been rebuilt yet, the game reports an explicit error naming the function — instead of substituting an invented “toy” driving model.

Features

Faithful to the original, comfortable on a modern PC

  • Original menus

    Language selection, title screen, main menu, name entry, vehicle selection and track preview run on the game's original graphics, fonts and texts.

  • One seamless game

    Menu → track and mode → race → results → menu. Everything happens in one game world, with no separate preview mode.

  • 60 steps per second

    The simulation runs at the original pace: 60 steps per second, regardless of the monitor's refresh rate. A game step including rendering takes about 3–5 ms.

  • Any monitor

    The picture fills the window at native resolution, with no bars and no stretching. Races use Hor+ — a wider view to the sides with the original vertical field of view. The HUD sticks to the screen edges.

  • 120, 144, 240 Hz

    On fast monitors no key presses get lost, and music, lights and loading screens keep the original pace. Optional interpolation smooths the motion.

  • Original assets

    Vehicle and track models, textures, fonts, music and sound effects all come from the original game files.

  • Rebuilt, not invented

    Every rebuilt behaviour must point to specific instructions in the pinned original EXE file. Decompiler pseudocode alone is not accepted as proof.

  • Original bugs fixed

    11 documented fixes, described separately from the recovered behaviour — for example a half-second pause every 7 minutes or so, caused by a 32-bit clock counter overflowing.

Requirements

  • Windows 10 or 11, 64-bit
  • DirectX 12 graphics card (feature level 11_0 or higher)
  • Microsoft Visual C++ Redistributable 2015–2022 (x64) — download from Microsoft
  • Your own copy of the original Stunt GP (CD or installation) — its files are not included
  • Keyboard

Package contents

  • StuntGP_NEW.exethe game (x64, DirectX 12)
  • START.cmdstarts the game with frame interpolation
  • START-MENU.cmdstarts the game without interpolation
  • README.txtinstructions (PL/EN)
  • data\retail\start-up configuration; copy the original game files here
  • save\card00\folder for saved settings

  1. Download

    Download the StuntGP_NEW-R1-program.zip archive and — to be safe — compare its SHA-256 checksum.

  2. Unpack

    Unpack the archive to a folder you can write to, for example the Desktop. From your own copy of Stunt GP copy the folders wads, graphics24, meshdata, sound into data\retail.

  3. Launch

    Double-click START.cmd. If a SmartScreen warning appears, choose “More info” → “Run anyway”.

  4. Play!

    On first launch, pick the menu language. On the title screen press ENTER, choose SINGLE PLAYER, a mode and a vehicle — and hit the track.

How it's made

  • From instructions, not guesswork

    Rebuilt behaviour must point to the pinned EXE file (SHA-256), the decompiled function and the exact instruction ranges. The decompilation is not the original source code.

  • Comparisons with the original

    Oracles run the original's unmodified instructions in the Unicorn emulator and compare the results with the new code — for example the pause and resume routines: 13,280 compared calls with no differences.

  • Strict builds

    C++23, compiled with /W4 /WX — warnings treated as errors — and /fp:strict for strict floating-point arithmetic.

  • New platform, clearly labelled

    The window, the DirectX 12 renderer, picture scaling and presentation pacing are new code — labelled as new, not as recovered game behaviour.

FAQ

Frequently asked questions

Is this the official game?

No. StuntGP NEW is an unofficial fan project, not affiliated with Team17 Software Ltd. Stunt GP and Team17 are registered trademarks of Team17 Software Limited.

Is it an emulator or a wrapper around the original EXE?

No. It is a native x64 program written from scratch in C++23, with a DirectX 12 renderer. The original executable is not run — it serves as the reference from which the game's modules are rebuilt.

Is the game finished?

Not yet. R1 is a work-in-progress version: the main path through the game works, but rare cases that have not been rebuilt yet end with an explicit error naming the function — instead of guessing the original behaviour.

Windows shows a warning when I launch it

StuntGP_NEW.exe is not digitally signed, so the SmartScreen filter may block it. Choose “More info” → “Run anyway”. To be safe, compare the SHA-256 checksum of the downloaded file with the value in the Download section.

MSVCP140.dll or VCRUNTIME140_1.dll is missing

Install the Microsoft Visual C++ Redistributable 2015–2022 (x64) from Microsoft: aka.ms/vs/17/release/vc_redist.x64.exe.

Does it work on a 144 Hz or 240 Hz monitor?

Yes. The game runs 60 steps per second regardless of the monitor's refresh rate, and START.cmd turns on frame interpolation, which smooths the motion.

I have an ultrawide monitor

The picture fills the whole window with no bars, and races show a wider view to the sides (Hor+). If you prefer the original 4:3 framing, launch the game with the --aspect-4x3 option.

Which languages does the game menu offer?

On first launch the game lets you choose one of the seven languages stored in the original data: English, Dutch, German, Swedish, Italian, Spanish or French. There is no Polish version of the game menu — Polish is available only on this website.

Where does the game save its settings?

In the save\card00 folder next to StuntGP_NEW.exe. That is why you should unpack the game somewhere you can write to — for example the Desktop, not Program Files.
